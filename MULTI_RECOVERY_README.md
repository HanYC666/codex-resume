# Codex multi-thread recovery

Installation, usage, retry behavior, terminal display, command-line options, and Ctrl+C summary definitions are maintained in the root [README.md](README.md). The status panel shows five tracked threads at once on terminals at least 16 lines tall.

Install the runtime dependency with `python -m pip install -r requirements.txt` inside a Python virtual environment. See the README for the complete macOS and Linux setup steps.
